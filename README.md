# PersonelTakipSistemi_OtomasyonProjesi
Bu Proje, işletmelerin personel süreçlerini dijital ortamda düzenli, güvenli ve verimli bir şekilde yönetmesini sağlamak amacıyla geliştirdiğim ilk otomasyon sistemimdir.

Projenin Amacı Nedir? 
Bu projenin temel amacı; kurum veya işletmelerdeki personel bilgilerinin, departman takibinin, iletişim bilgilerinin ve özlük verilerinin dijital ortamda düzenli, güvenli ve hızlı bir şekilde saklanıp yönetilmesini sağlamaktır. Kağıt üzerinde veya dağınık dosyalarda tutulan personel takibini tek bir masaüstü arayüzünde toplar.

Hangi Teknolojiler Kullandım?
Programlama Dili: C# (.NET / Windows Forms)
Veritabanı: Microsoft SQL Server (MS SQL)
Arayüz Tasarımı: WinForms UI Controls 
Yapılandırma: App.config 

Sistem Nasıl Çalışır ve Hangi Özellikleri Barındırır? 
Veritabanı Entegrasyonu: MS SQL ile kurulan bağlantı sayesinde tüm personel verileri kalıcı olarak veri tabanında saklanır.
CRUD İşlemleri: Yeni personel kaydı ekleme, mevcut bilgileri güncelleme, personeli sistemden silme ve verileri anlık olarak listeleyebilme.
Kullanıcı Dostu Arayüz: Windows Forms ile geliştirilen sade ve anlaşılır form yapısı sayesinde operasyonlar kolayca yönetilir.
Merkezi Yapı: App.config dosyası üzerinden esnek veritabanı bağlantı yönetimi sunar.
